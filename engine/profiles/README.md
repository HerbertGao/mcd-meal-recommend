# Profiles

Do **not** commit real `lunch.json` / `breakfast.json` (store, address, personal prefs).

1. Copy a template: `cp templates/lunch.example.json lunch.json`
2. Fill `storeCode` / `beCode` / `addressId` / `budgetFen` / families
3. Keep real profiles local or in a private overlay (gitignored)

Templates are examples only.
